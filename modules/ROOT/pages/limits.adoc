== Upstream Service Limits

API Manager limits the number of upstream services you can expose through a single consumer endpoint.

[%header%autowidth.spread,cols="a,>.<a,a"]
|===
| Limit | Value | Notes
| Upstreams per API
| 50
| 
| Routes per API
| 50
| 
| Upstreams per route
| 10
| 
|===
