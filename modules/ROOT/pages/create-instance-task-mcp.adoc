== Add a New MCP Server Instance

. Navigate to *Anypoint Platform* > *API Manager*.
. In *API Administration*, click *Add* and select *Protect MCP server*.
. Select a Flex Gateway to deploy the server instance to from the list under *Select a gateway*.
+
[NOTE]
--
If you don't see a Flex Gateway listed, or you see a Flex Gateway but its status is *Not Running*,
See xref:gateway::flex-install.adoc[Install Flex Gateway] and xref:gateway::flex-conn-reg-run.adoc[Register and Run in Connected Mode] for more information.
--

. Click *Next*.


. Select an MCP from the following options:
* *Select MCP server from Exchange*: If you have an MCP server shared with you through Exchange that you want to manage.
[arabic]
.. Select the  from the list under **Select MCP server**. You can search for a specific server if needed.

* *Register a new MCP server*: If you want to create a new MCP server asset.
[arabic]
.. Enter a *MCP server name* for the new MCP server asset.
+
NOTE: Your server is published to in Exchange after it is protected.

. Click *Next*.
